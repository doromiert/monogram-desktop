# Monogram mobile category icons

Unmodified highest-density WebP resources copied from Monogram mobile,
`TMessagesProj/src/main/res/drawable-xxhdpi/`. Source selection follows
`EmojiTabsStrip.java`; favorites, recent, eight built-in categories and settings.

Telegram Android upstream resources are GPL-2.0-or-later, as documented in
mobile/README.md. The upstream license is preserved in COPYING. Native rendering
may tint/scale these original masks; the source bytes are unchanged.
See SOURCES.json for exact file paths and SHA-256 digests.

`default-recent.json` preserves Emoji.java DEFAULT_RECENT order; built-in history
uses its initial descending usage weights, mobile frequency order and 48-item cap.
